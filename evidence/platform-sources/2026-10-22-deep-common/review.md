# 两平台共同依据：2026-10-22 多轮补核

实际查阅：2026-10-22（Asia/Shanghai）。这是公开研究的人工审阅，不是法律意见、最新性认证或用户批准的基线。未登录、读取 Cookie／浏览器或上传私人材料；未操作真实账号、提交投诉／申请、发布、付款。原始 txt／机器 json 仅本地保存并被 Git 忽略，不要求公开第三方全文。旧批审阅与失败不覆盖。

## 研究过程与真实性处理

1. 第一轮：重读国家网信办 AI 标识办法及市场监管总局互联网广告管理办法，核对义务主体、条款及本身日期。
2. 第二轮：检索并读取市场监管总局广告可识别性指南，交叉核对“是否构成广告”“如何可识别”与 AI 标识，避免把所有披露混成同一个标签。
3. 第三轮：以 2026、修改／修订／废止定向检索后续官方材料，再读取 2026 年网信执法通报及广告监管工作要点。它们增加后续执行背景，不证明穷尽检索或所有旧条款持续未改。

发现路线为 agent-reach 匿名 Exa；第三轮 Exa MCP 三次明确返回 HTTP 429，错误包含 `You've hit Exa's free MCP rate limit.`，没有完成这些请求。其后改用现有 Bing 搜索工具发现候选（未改变用户首选引擎设置），仅对选定官方 URL 用仓库来源工具显式 `--fetch`、匿名 Jina 读取。没有付费或索取 API Key。不是把失败记为无新规。

阅读器 200、抓取时间、页面当前日期、索引日期、指纹及 URL 年份均不证明修订／现行性。下列五份机器报告均为 `baseline-needed`、`authority_updated: false`，没有旧基线比较；源站 HTTP 状态均 unknown。首次捕获仍需人工按动作核对，不能擅自写“用户已批准”。

### COMMON-AI：《人工智能生成合成内容标识办法》

- 官方 URL：[国家网信办通知及十四条正文](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)。发布主体：国家互联网信息办公室、工业和信息化部、公安部、国家广播电视总局；页面来源中国网信网。
- 日期：文件 2025-03-07；页面发布 2025-03-14；更新 unknown；施行 2025-09-01；查阅 2026-10-22。
- 范围：第二条所列网络信息服务提供者的标识活动；第十条直接涉及用户使用网络信息内容传播服务发布生成合成内容。本次用于中国大陆小红书／抖音，不推断 TikTok／境外 rednote 适用。
- 实读：通知与第一至十四条完整提取文字正文。第三条定义含文本、图片、音频、视频、虚拟场景。第六条是传播服务者措施；第十条是用户主动声明并使用平台功能，以及不得恶意删除、篡改、伪造、隐匿标识。
- 支撑：平台旧文“建议说明”或 2024 指南“鼓励提示”不能豁免后来第十条及平台的适用要求；亦不能把服务提供者全部元数据实现义务强加普通创作者。
- 未核实：每一种润色／构思的个案边界、两平台当前客户端功能及账号结果。讲 AI 不等于由 AI 生成。触发：首次合成发布、素材或工具变化、修订／平台标识通知。
- 本地捕获 `ai-label-r1.txt`，机器报告 `ai-label-r1.json`（均不版本化）。

## 共同结论

法律上的广告可识别性、商业利益关系透明、平台合作工具／准入、AI 生成声明是不同检查。相同法律底线可供两平台分别引用；具体平台标签、交易、专业领域、协作或投诉条件必须保留各自官方依据及未核实项。用户批准、平台许可、实际技术权限仍分开；本批不修改私人账号、委托或权威规则基线，不启用后台抓取。
