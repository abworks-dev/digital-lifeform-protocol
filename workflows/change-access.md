# 授权变更闭环（手动实验版）

用途：新增、调整、撤回协作者或 Agent 委托时，分清人的批准、本地委托和平台实际权限。字段与状态只由[记录约定](../docs/RECORDS.md#授权变更的三个独立层面)定义；采用现有 [decision](../templates/decision.md)、[delegation](../templates/delegation.md) 和 [account](../templates/account.md)，不另建权限台账。

输入：用户指定的资源/委托、期望变化、相关记录、已许可的读取及写入范围。平台手动操作由本人或另获授权的人执行，本流程和文档维护权限不授予 Agent 登录、邀请、授权、改设置或撤权的能力。

## 1. 提出变化

只读指定记录；列出当前带时间的已核实范围、拟变更后的对象/角色/动作/资源、有效期、到期或撤销方式、理由及风险。区分实际所有者、平台登记主体、管理员和恢复责任人；不知道就 unknown。

优先平台原生最小角色，不建议共享主账号密码。不支持细粒度角色、有效期或相关能力未知时，说明限制并给出本人操作或暂不委托的替代，不用共享凭据补洞。涉及所有权、结算、恢复入口或公开关联时单独提出，不能夹在普通编辑权限中一起获批。

## 2. 逐项批准与写入范围

向用户展示前后差异、目标 ID/文件/字段、拟保存的历史事件、人工执行者、验证方式及失败后的处理。每轮只问最多两个高影响缺口。用户可以只批准一项、拒绝或要求只在对话讨论。

批准内容与授权写记录是两件事；明确此次是否允许保存 decision，以及闭环后续证据、哪些 account/delegation 字段可以随已核实结果更新。不涵盖的写入再询问。没有写授权连 draft 也不落盘，不因读取到记录或第三方批准截图就扩大授权。

获准保存时记录批准主体、时间和精确范围，保留旧观察及历史决定，不把拟授予权限写成平台已生效。对涉及平台授权的新增/扩大权限，未执行且验证前不凭批准将委托记为 active。用户撤回或到期时立即停止依赖旧委托，即使没有写授权也停止行为；可在获准后记录 revoked/expired，但必须注明平台撤权仍未核实。

## 3. 人工执行与结果收集

由本人或另获授权的人在平台完成批准的操作。Agent 仅给检查清单，不代为操作或索取密码、Token、Cookie、恢复码。人工报告按证据情况记录为 reported，不因“我点过了”断言成功。邀请已发送、对方已接受和实际获得权限分别观察；未接受不能算生效。

只收必要的非秘密摘要或私有证据指针；截图需人工去除不相关账号、联系方式和秘密，不要求上传到模型或公开仓库。没有可用证据时保留未知，不让用户提供秘密来证明。

若是纯本地 Agent 委托而无平台操作，只核对获准的本地工具和读写边界，不虚构平台邀请或角色。不明控制标 unknown；可用工具不代表已获授权，提示词也不是强隔离。

## 4. 独立核对实际结果

按实际适用环境分支核对，记录核验人、时点、证据来源及限制。“独立核对”是再次检查结果，不要求单人用户虚构第二位人员。

- 涉及平台权限：本人或获准核验者检查当前成员/角色/权限列表及可用的非破坏性证据，逐项比较批准与实际范围。撤回时检查目标资源、已知关联入口、直接与继承/群组权限；只核对授权可见范围，范围外标未覆盖。邀请消息删除、按钮点击或文档 revoked 都不等于对方失去全部访问；到期也不假定平台自动撤权。
- 纯本地委托：核对明确的本地意愿、允许动作、输入与读写范围、有效期以及实际工具/控制证据；平台执行/角色核查注明不适用及理由。有效批准且所需能力与边界已核对后，才在获准范围内将本地委托记 active。撤回/到期则停止旧任务，按写授权记录 revoked/expired；若技术能力仍存在，如实记录，不能把行为停止说成系统已移除能力。控制未核实/未实现的部分单列，不能声称强隔离。

两种分支都不能用试发帖、试付款、删账号等破坏性动作作探针；工具清单与模型自述不能单独证明实际读写隔离。

失败、部分成功、能力残留或证据冲突时，保留每个目标的实际结果、下一责任人和期限，不标全量完成。撤回失败时仍不得恢复旧委托执行；告知本人并请求人工处理，不擅改其他账号。

## 5. 据证更新并复核

仅在既有写授权涵盖范围内追加事件/证据和必要确认信息；超出范围再次确认。decision 保存前后差异、批准、人工执行、验证和台账更新各步的主体/时间/结果；account 保存带时点的能力观察，delegation 保存本地委托意愿，通过 links 引用同一变更依据，不复制两套事件历史。

如果写入失败或证据不足，说明本地意愿、适用的技术/平台结果和记录更新各自到哪一步，保留未完成项，不声称闭环。记录确认与实际权限语义分开；复核按[定期与事件流程](review-accounts.md)追踪。

输出：已批准范围、人工执行/验证/保存分别完成或未完成的结果、证据、责任人与下次检查。拒绝不会生成有效授权；旧决定、失败记录和撤回理由不删除。涉及平台变更但尚未执行/验证时，只交付平台方案与待办，不报告平台权限已改变；纯本地委托可据对应证据报告获准的本地意愿及记录更新结果，不虚构平台步骤或技术控制生效。
