# 新项目账号评估

输入：项目目标、受众、交易与协作需求、已确认记录。

1. 读取相关身份和已有账号，不扫描无关私人信息。
2. 检查复用机会；比较维持原状、复用、拆分三个选项。
3. 按受众、隐私、售后、交接、维护成本给出理由；缺失信息明确标 unknown。
4. 输出拟新增或变更记录与公开关联影响，等待用户确认。
5. 在获得写入授权后更新 draft/confirmed 与决策历史，不改写过去判断。

拒绝分支：用户不愿公开关联就给出不关联方案；用户要求登录发帖等外部动作时，说明本流程无该能力和授权，停止该动作。账号创建仅生成清单，不执行注册。

输出：最小配置、复用/拆分理由、维护责任、后续复核项。验证：所有引用可解析、关键事实有来源、变更确认可追溯。
