- 产品：本轮仅中国大陆**抖音**普通个人内容账号；不是 TikTok，也不推定抖音关联版本的功能和权限相同。
- 企业／机构认证、电商／本地生活、直播／打赏、广告合作／巨量星图等，只识别升级复核入口；专项准入、交易、角色权限和当前界面**未覆盖**。普通号可以发布内容，不等于可以开课、带货、接广告或分享登录权限。
- [规则与证据](rules.md)：官方要求、读取范围、未知和触发条件。
- [手动任务指南](guide.md)：账号方案／创建准备／旧号接入、唯一主档、主页与正常内容发布检查；其他职责从下表进入独立专题。
- [虚构闭环与验证记录](../../examples/douyin-validation.md)：此前独立于小红书历史结果的有限验证；不继承为本次拆分后的业务行为通过。
- [专题拆分与离线回归](../../tests/README.md#11-抖音专题拆分与离线回归2026-10-22)：本次结构、静态检查和离线结果，未新增模型／保存／平台操作测试。

## 每次使用的三个独立门槛

1. **用户批准**：允许做什么、改哪些本地文件／字段、期限及可撤回范围。批准保存方案 ≠ 批准注册／改名／发布。
2. **平台许可**：这个产品、账号类型和动作有没有适用依据；个人协议的本人使用限制见 [DY-S01／DY-S03](rules.md#官方来源)。unknown 不是允许，也不阻塞与该动作无关的本地方案整理。
3. **实际技术权限**：本轮不登录，故当前角色、可见入口和权限状态均 unknown。即使以后能登录，也不说明前两项满足。

恢复登录不恢复已撤回／过期委托；本地标记 revoked 不说明平台权限已解除。用户拒绝身份关联时，不记隐藏映射、不公开私人身份；也不承诺抖音与关联版本、实名或推荐关系绝对隔离。

## 使用前复核

普通内容、主页和 AI 事项使用前对照 [证据](rules.md)，记录本次实际核验范围。账号访问／协作、商业化、处罚恢复、投诉／隐私及注销等高影响动作，每次先由本人在官方入口核对适用正文与当前条件。资料缺失、过时或冲突时，保留 unknown／stale／conflicting 和阻塞的具体动作，不凭最后抓取日放行。

本轮没有真实平台结果。现有离线测试、小红书旧验证、HTTP 200 和内容指纹均不能替代抖音逐项验证。
