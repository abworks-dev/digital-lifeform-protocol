## 使用位置与责任边界

先实际读取任务主流程：[新项目评估](../../workflows/add-project.md)、[发布与商业化](../../workflows/publish-and-commercialize.md)、[授权变更](../../workflows/change-access.md)或[复核](../../workflows/review-accounts.md)，再按需读取本参考。本页不替代主流程，不新增 schema、授权状态或私人台账；证据与状态唯一语义见[记录约定](../../docs/RECORDS.md#规则与证据)。

1. 明确地区、主体/账号类型、具体动作及交易路径。普通创作者、专业号、店铺、蒲公英合作与小程序不能互相代替；未确定的类型和资格保持 unknown。
2. 区分下表的已读原文、搜索节选和未读正文；表中查阅日期不是发布日期、生效日或未来许可。即使已读原文，也必须核对当前动作的适用性与后续规则，不能仅凭本页宣布平台允许。
3. 只核实与任务有关的问题；必要材料不可访问时，列人工核验清单，暂停依赖该材料的交易/推广结论，不阻止无关且获准的内容草拟。不得以测试发布、私信交易或另开号来验证/绕过限制。
4. 如获准保存，使用原有 decision 的证据小节并由相关记录 ID 引用，按实际读取情况填写质量与日期；不整页复制到私有入口、profile 或长期记忆。关键关联和保存各自须获确认；无写授权连草稿也不落盘。

历史增量见[外链复核记录](#2026-10-21-外链复核增量)：该轮S04未取得正文，S06取得《交易导流规则》，不是课程准入依据。更晚同日的检测快照与人工审阅范围见[归档审阅记录](../../evidence/platform-sources/2026-10-21/review.md)：S04后续恢复取得资格正文，不能据此断言政策新改或当前资格通过。下方清单及观察保留其建立时范围与日期，不覆盖失败历史、不自动滚动复核日。

### 提醒后如何处理

1. 按[使用前复核](../README.md#使用前复核)检查当前日期、到期/触发项和授权；没有公开读取授权时先请求，不因收到提醒自动联网。
2. 输出待核/无需本轮/已核指定范围、旧新来源与日期、变化或冲突、受影响动作与仍可做任务。本人操作及账号资格与公开文本核对分开。
3. 只有获准保存才在本页追加观察，说明读取范围、失败及待办，并据实际结果更新本清单日期；不覆盖历史来源，不动私人主档/委托。
4. 提醒收到、已读或点击不表示复核完成；主机停机/会话不可达可能影响提醒投递，使用本项目前仍须核清单，不依赖提醒保证新鲜。可通过本会话提醒管理调整/取消，不在仓库保存会话专用调度ID。

## 按动作核查，而不是按账号名放行

| 场景 | 本参考提供的核查路径 | 未核实前的边界 |

| 委托编辑、共用账号或交接 | 查该类型是否存在官方协作角色、具体能力和批准渠道；按授权变更主流程核对范围与有效期。 | 不把本地 delegation=active 当成平台同意共享账号；不索取密码/Cookie/验证码，不自动邀请或转让。 |

## 输出与人工复核

每次输出应包含：动作/账号类型/地区与路径、已核对事实及来源范围、建议、unknown/冲突/过时项、阻断哪些动作与仍可做什么、所需人工材料、获准保存范围。不用“平台适配完成”替代当前内容/交易的逐项批准。

人工可在自己的官方客户端/后台核对：适用规则标题及版本、生效与适用主体、条款正文、可用协作角色、声明工具和商品准入结果。只向 Agent 提供获准的去标识节选与非秘密观察；不提供登录、恢复或买家材料。人工自述与独立核验分别记录，未核实结果不升级。

规则更新、动作/账号类型/地区或利益关系变化、平台提示/拒审、用户投诉触发重新核验。结束旧会话后再审阅框架变化；不自动联网更新规则、启动定时任务、重签接入契约或迁移私人记录。发现冲突时保留来源与日期，按[复核流程](../../workflows/review-accounts.md)列责任与期限，由用户决定下一步。

虚构验收见 [A21–A25](../../examples/acceptance-tests.md#p2-小红书文档适配验收新增用例尚未执行)。本页写成不代表这些模型/工具测试已通过。
