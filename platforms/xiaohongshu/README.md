## 共同边界

先实际读取[平台共同边界](../README.md#共同边界)与[适配约定](../README.md#轻量平台适配约定)，再读本页所选任务主流程及平台差异；本节保留旧锚点，不维护第二份通用规则。

平台目录标识为 xiaohongshu，产品为小红书；境外 rednote 仅作相关名称提示，不视为同一规则适配。具体地区/注册地与普通号、专业号、店铺、小程序等类型必须另核。上表六类任务均有手动文档覆盖，不代表注册、协作、恢复、投诉或交易功能已核实可用；实际能力多为 unknown。没有当前资格证据时不放行相关动作。

本平台目录不登录账号、不注册、不发布、不采集后台，也不保证增长或不被封禁。先明确地区与账号类型；小红书中国境内注册用户协议不默认适用于境外 rednote。

历史规则参考保留 2026-10-16 及同日首次限定范围复核；后续六条外链观察见[复核增量](rules.md#2026-10-21-外链复核增量)：该轮S04未取得正文，S06取得交易导流规则文字，不是课程准入依据。更晚同日试跑的S04已恢复取得资格段落，见[归档审阅范围](../../evidence/platform-sources/2026-10-21/review.md)，不覆盖旧失败或宣称政策已变。没有核实具体客户端入口、多账号额度、后台权限、课程准入或处罚算法。

无旧号也可以先制定筹备方案。确认方案不代表账号已存在；拟议账号沿用 existing / proposed / unknown 的[既有约定](../../docs/RECORDS.md)，不为指南新增 schema。私人资料不写入公开框架。
