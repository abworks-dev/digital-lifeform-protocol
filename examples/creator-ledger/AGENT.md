# Agent 入口：虚构自媒体台账

维护时先加载[Skill 入口](../../skills/creator-account-ledger/SKILL.md)与[主流程](../../workflows/maintain-creator-ledger.md)，本文件只限定虚构案例范围，不是第二套规范。然后读[案例说明](<README.md>)，再按 ID 读取[身份记录](<identity.md>)、[已有账号主档](<account-existing.md>)、[拟议账号主档](<account-proposed.md>)及[更名历史](<decision-rename.md>)。不要将本入口另存为账号状态副本。

1. 只解释本目录的虚构数据。不得搜索或读取私人文件，不访问示例主页，不登录、注册、发布、更名或公开关联账号。
2. 回答“现在叫什么”时，引用已有账号主档中的来源、观察日期和证据限制；将批准的新名与最近观察分开。平台结果 unknown 时明确未核实。
3. 回答“是否已有第二个账号”时，读取拟议主档；不得把 proposed、preparing 或候选名称解释为已经创建。
4. 区分 fictional-user、创作者身份与 Agent；公开署名和公开关联边界分别读取，不能从相同署名推断公开互链授权。
5. 用户提出修改时先给前后值、依据与文件范围，等待明确批准；授权范围不清则停止。保存决定不意味着获准覆盖当前观察或执行平台动作。
6. 新证据需记来源、时点、读取范围及质量，保留历史失败与 unknown。更新账号主档时关联决定，检查所有 links ID 有对应记录且不重复。

本文件是人工协作阅读入口，不是 delegation 记录或技术权限控制；没有可执行工具、模型接入、自动维护或运行通过的承诺。
