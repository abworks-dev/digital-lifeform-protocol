# 快速开始（手动实验版）

推荐方式是**首次显式接入，以后在自己的工作空间直接提任务**；也可先用公开虚构材料体验一次查询。**不必先注册账号、安装全局 Skill、创建私人目录或填完所有模板。** 本项目提供文件与指令，模型、文件工具和实际权限由你选择的 Agent 宿主提供。

## 0. 首次显式接入，以后直接提任务

### 从哪里发起、在哪里生效

可以从任意能访问框架和目标工作空间的会话发起，不限本项目工作区；推荐在准备日常使用的独立私人工作空间打开现有 Agent。工具只能访问当前空间时，先切换到目标空间，不绕过工具边界。公开框架仓库用于维护方法，不用于保存真实台账。

| 方式 | 实际作用范围 |
|---|---|
| 明确让 Agent 读取一次框架 | 通常仅当前会话；新会话不保证记得 |
| 获准在目标空间保存轻量入口 | 仅该空间、实际支持并加载入口的宿主；需新会话验证 |
| 用户级/全局 Skill 安装 | 本快速开始不执行；须另行明确授权，发现能力也不等于私人资料读取权 |

克隆仓库、打开目录、读取文档均不会自动安装全局 Skill。本项目没有统一安装器或跨所有宿主自动激活机制。

### 第一次只说接入目标

替换路径后发送下面的请求即可；不必先知道内部文件清单或任务编号。这里只允许检查指定框架及目标空间中明确指定的入口文件（例如已知存在的 AGENTS.md），不扫描私人资料；入口位置不明时先由 Agent 询问并展示拟检查路径。

```text
请使用位于 <框架绝对路径> 的框架，协助接入 <目标工作空间绝对路径>。
先读取框架的 skills/creator-account-ledger/SKILL.md 和 docs/HARNESS.md，
检查是否已有可复用入口；位置不明先问我，不扫描私人资料。
展示最小改动、作用范围与数据外发边界，等我确认再写入。
不要安装全局 Skill、改宿主全局配置、复制框架正文或创建第二套台账。
```

Agent 按[接入步骤](HARNESS.md#工作空间一次接入与日常恢复)核对宿主、路径、已有入口与主档；只问必要缺口。先展示入口拟写位置和完整内容，获准后才保存。轻量入口只指向框架和获准记录，不能把文档指令当作数据访问授权。外发边界未澄清时只用虚构材料，不读取真实台账。

完成时应分别说明“入口已保存”“本会话已读取”“新会话是否实际加载”。用新会话、无敏感测试材料核对；未经新会话验证，只能标为待验证，不能称接入已生效。加载失败回退到显式读取；不自动改全局配置或复制规范。

### 以后直接说要做什么

在已验证入口的目标工作空间，可以直接说：

- “我准备做一个抖音科技账号，先帮我比较账号方案。”
- “这个账号换定位了，先列出需要确认的变更，不保存。”
- “复核我指定的这些账号，看看哪些事项还没闭环。”

Agent 从入口恢复获准上下文，选择 T1–T5，只追问缺口；已有且仍适用的信息不要求每轮重填。没有有效读取范围时先询问；新会话不继承旧对话的一次性保存许可，关键选择和具体写入仍按任务确认。工作空间、宿主、框架基线、数据边界或授权变化时重新核对受影响项。

当前能力以账号方案、盘点、查询、变更和复核为主；研究、文案、头像或视频制作可另借现有能力，不冒称完整创作者启动系统已实现。文档接入不是自动运营、安全隔离或永久授权。

## 1. 先跑一次虚构查询

1. 准备可访问的框架目录和一个现有 Agent。能读取文件就显式提供入口；只能对话时，可手动提供下述完整相关文本并标注来源/基线，不能让 Agent 冒称已读本地文件。未提供完整依赖时先补全，不凭记忆模拟运行。
2. 浏览[虚构实例](../examples/creator-ledger/README.md)，只用 fictional-user、虚构平台和示例域名。不接入私人数据，也不访问案例主页。
3. 替换下面的框架路径并发送请求；路径未替换或不可读时先解决路径问题，不猜私人位置。

```text
框架根目录：<可访问的框架绝对路径>；本次任务：T3 单项查询，先做虚构演示。
允许读取框架内 skills/creator-account-ledger/SKILL.md、docs/HARNESS.md、
docs/RECORDS.md、docs/SECURITY.md、workflows/maintain-creator-ledger.md。
虚构材料只允许读取 examples/creator-ledger/ 下的 README.md、AGENT.md、
account-existing.md、account-proposed.md、decision-rename.md、identity.md。
私人目录：不使用；输入仅为上述公开虚构材料，允许用于本次模型请求与会话历史。
请回答：已有账号最近观察到的名称是什么？第二个账号是否已创建？
给出记录 ID、主档位置、来源、日期、证据范围和未知项。
不写任何文件，不扫描其他目录，不联网或访问示例主页，不注册、登录或发布。
需要额外读取先问我；依赖不可读则说明缺口，不编造已读取结果。
```

4. 核对交付：回答应从主档区分最近名称观察与批准的新名，第二号仍是拟议方案；没有文件写入或外部动作。来源不足时明确 unknown。这是一次只读练习，不是安装发现、自动触发、宿主隔离或平台真实状态的验证。

支持目录型 Skill 的宿主可按其自身机制加载[Skill 入口](../skills/creator-account-ledger/SKILL.md)，但要保留可读框架依赖；本项目不自动安装或激活。先显式读取即可，不需要为了演示改宿主配置。

## 2. 选你真正要做的任务

| 目标 | 进入哪个任务 |
|---|---|
| 没有账号、想比较定位与账号方案 | [T1 账号方案](../workflows/maintain-creator-ledger.md#t1-账号方案) |
| 已有几个账号，想弄清身份与用途 | [T2 已有账号盘点](../workflows/maintain-creator-ledger.md#t2-已有账号盘点) |
| 想问名称、状态或某段历史 | [T3 单项查询](../workflows/maintain-creator-ledger.md#t3-单项查询) |
| 想改名、换维护人、调整关系或取消筹备 | [T4 记录变更](../workflows/maintain-creator-ledger.md#t4-记录变更) |
| 想找风险、准备交接或退出 | [T5 复核、交接与退出检查](../workflows/maintain-creator-ledger.md#t5-复核交接与退出检查) |

输入、读取范围、最小输出、确认点和完成条件以对应任务为准。无旧号时直接用目标、资源和隐私约束讨论方案，不强迫建立台账或扫描私人目录。

## 3. 接真实资料前，先确定范围

按[最小接入输入](HARNESS.md#2-最小接入输入)核对实际宿主、模型/服务、工具执行环境、框架基线、路径、工具和数据边界；不知道的项目写 unknown，不能直接记成“安全”“已关闭”或“已兼容”。模型、历史、记忆和同步的边界未澄清前，继续只用虚构材料。

- **读取前**：用户指定独立私人工作空间、本次允许的文件与内容范围、是否允许补读引用，以及可接受的模型外发/留存范围。不要发送秘密或扫描整个知识库。已有主档优先使用，不建立第二份台账。
- **写入前**：先在对话展示文件/记录 ID、字段、前后值、依据、影响与不执行项；分别取得内容确认和具体保存授权。即使只是草稿也不先写。关键关联、归属或权限变化重新确认；拒绝或未回答部分不保存。
- **外部动作前**：本框架不执行注册、登录、发布、付款、撤权或注销；需要时按专项检查由本人另行处理。保存方案、decision 或 review 都不代表外部动作完成或获得许可。

以下长请求是**未配置持久入口时的手动兜底或精确范围测试**，不是日常必填表。已有获准且实际加载的入口时，直接描述任务，Agent 复用仍有效的信息，只补问缺口；不自动扩大读取范围或继承临时保存批准。手动使用时先补全已核实的信息，不把占位符当授权。不了解外发边界时不要填写或附上真实资料。

```text
请显式读取 <框架根目录>/skills/creator-account-ledger/SKILL.md、记录约定、安全边界与台账主流程。
框架版本/提交及本地修改：<已核实基线，未知写 unknown>。
本次任务：<T1–T5 中的一条及具体问题>；本次提供信息：<获准的最少脱敏输入>。
私人主档目录：<确认路径；只讨论方案时填“不使用”>。
本次只允许读取：<明确文件清单；无则填“无”>；不自动沿引用扩读。
已核实的数据边界及仍未知项：<模型/中转、历史、记忆、同步等>。
本人允许本次发送和留存的内容范围：<范围>；边界不清先停在虚构演示。
先只在对话回答、盘点或提议，不写文件。需保存时先列具体路径、字段和前后值等我确认。
不访问主页、不操作账号；额外读取或范围变化先问我。
```

无获准目录/写工具时只交付建议或待保存草案，不声称已建档。获准首次建档才按需使用[模板](../templates/account.md)，为记录指定唯一 ID；不要把私人资料写入框架。模板相对链接在私有目录中可能失效，按确认的框架路径引用，不复制第二套规则。

需要更广的身份/项目初始化时，再按[初始化流程](../workflows/onboard.md)及[综合虚构案例](../examples/solo-builder.md)进行；新增项目用[新增项目流程](../workflows/add-project.md)。不要求为了台账查询先完成综合初始化。

## 日常治理与维护（P0 手动流程）

- 需要管理依赖时，按 [account 模板](../templates/account.md) 补充责任、关键权限、恢复/服务/续费依赖；语义以 [记录约定](RECORDS.md#账号治理与依赖) 为准。只记录非秘密元数据，未知保持 unknown，不要求一次填满。
- 协作者加入、权限变化、合作结束或委托到期时，走 [授权变更闭环](../workflows/change-access.md)：提出、逐项批准、人工执行、验证、按授权更新台账。不要把本地 revoked 当作平台撤权成功。
- 按用户约定的日期或变化事件，运行 [定期与事件复核](../workflows/review-accounts.md)，留下未解决项、责任人和期限；这不是自动调度或账号清理。
- 对重要规则判断，在 [decision 模板](../templates/decision.md) 保存来源及适用范围、日期、读取范围、证据质量和复核条件；其他记录用 ID 引用。用户确认记录不自动核实来源。

所有新增小节均为可选试验；不批量补写或迁移旧记录。模板中的相对文档链接用于在框架仓库内浏览；复制到私有目录后，按已确认的框架绝对路径引用相应文档，不为修复链接复制一套框架规则。任何私人记录写入仍需用户授权。

框架有更新时，先结束旧会话、比较约定与流程，再确认对私人记录的影响；不自动更新接入基线或迁移。新增 P0 验收用例同样须实际执行才算环境通过。

## 三类专项维护（P1 人工检查）

- 停用账号、交接资源或退出项目：用[退出检查](../workflows/exit-or-handoff.md)，先检查内容保留、权限与反向依赖、续费、订单/退款/售后、必要留存；不要把停用、转让和注销混成一次批准。
- 疑似失陷、错发、误关联、平台处罚或恢复入口失效：用[事件处置](../workflows/respond-to-incident.md)，最小保全证据，区分本人止损、人工执行、结果核验与获准保存。紧急不等于给 Agent 外部操作权。
- 发布、推广或课程/服务交易：用[发布与商业化检查](../workflows/publish-and-commercialize.md)，核对版权、AI 标识、利益披露、宣传依据、当前适用准入和履约/售后。必要证据未知则暂缓相关动作，不以自建站或私信收款绕过限制。

三类检查均复用现有 decision/review/account/delegation，不复制新规则库或客户台账。可以只在对话中检查；任何保存仍须指定文件和字段授权，操作批准不能代替写授权。P1 的 A18–A20 是待执行规范；文档完整不等于模型或工具已通过。规则适用性要在实际动作前核验，不据此获得合规保证或发布许可。

## 平台参考（P2 首批：小红书）

先从[平台指南目录](../platforms/README.md)选择平台；小红书按[平台入口](../platforms/xiaohongshu/README.md)区分[规则与证据](../platforms/xiaohongshu/rules.md)和[本人创建、健康运营手动指南](../platforms/xiaohongshu/guide.md)。在读取任务主流程后，按需讨论注册准备、主页建设、首批内容、正常运营与异常申诉；无旧号不妨碍讨论方案，确认方案不等于已注册。它只是创作者从零启动的通用手动指南子集，不代替主流程，不自动注册、登录或发布，也不提供养号防封保证。

涉及账号方案、协作或商业内容时，先明确地区、账号/主体类型、动作与交易路径，再逐来源核对正文、日期和适用性。规则页保留历史核验范围，不因本次指南接入就视为现行政策已复核。

企业专业号/小程序要求不外推普通账号上限；商业身份、利益关联与 AI 标识分别核对。课程准入和具体导流细则证据不足时，暂缓相应上线/交易结论，不以建站、私信或换号绕过。新增 A21–A25 仍为未执行规范；不自动改私人台账或接入契约。

## 接入前后检查

- 使用 Hermes 时，先按 [接入指南](HERMES.md) 核实本机版本、实际运行环境、专用 profile 和上下文加载；先确认私有路径，再初始化。
- 调用模型前阅读 [安全与隐私边界](SECURITY.md)：profile 分离、工具限制和系统隔离不是同一件事；本地文件也可能进入模型请求与历史。
- 用真实资料前执行 [虚构接入验收集](../examples/acceptance-tests.md)，同时检查回复、工具调用和文件变化，不把一次模型拒绝当作隔离证明。

暂不提供安装器、自动校验器、定时维护或外部账号操作。不宣称任意 Agent 兼容。Hermes 指南记录了一次特定版本接入的人工观察范围，未附可独立复验的公开通过报告；验收集是待执行规范，不能据此声称自己的环境已经通过。
