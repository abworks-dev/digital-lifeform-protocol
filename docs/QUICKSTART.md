# 快速开始（手动实验版）

1. 在公开仓库之外创建自己的私有工作目录；不要把真实资料提交到本项目。
2. 阅读 [记录约定](RECORDS.md) 和 [虚构案例](../examples/solo-builder.md)。复制所需 templates 文件到私有目录，为记录指定唯一 ID。
3. 在你选择的 Agent 中提供 [初始化流程](../workflows/onboard.md)，明确可读取的目录、允许写入范围与模型数据外发边界。
4. 先得到匿名草案，确认角色、归属和公开关联后再写入真实记录。不要一次授权所有外部操作。
5. 新项目使用 [新增项目流程](../workflows/add-project.md)；手动复核字段、引用与确认状态。

暂不提供安装器、自动校验器、定时维护或外部账号操作。不宣称任意 Agent 兼容。只有真正跑过的运行环境才能列为已验证；目前尚无完整运行验证记录。
