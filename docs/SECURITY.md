# 安全与隐私边界（实验版）

本项目提供记录约定、建议方法和手动流程，不提供身份验证、访问控制系统或安全认证。核心规则仍在 [项目边界](PROJECT.md)、[记录约定](RECORDS.md) 和对应工作流；本文解释这些规则不能替代的控制层。

## 分清四层边界

| 层 | 可以做什么 | 不能据此宣称什么 |
|---|---|---|
| 用户侧指令/委托记录 | 约定范围、确认步骤与拒绝条件 | 模型绝不越权、文本授权已被系统强制执行 |
| profile / 工作空间分离 | 分开配置、会话、记忆和私人台账 | 同机 profile 无法读取彼此文件 |
| 工具权限 | 移除终端/浏览器等能力，限制特定工具写路径 | 所有工具、插件、子进程共享同一沙箱；写限制同时限制读 |
| 系统权限/容器挂载/网络控制 | 在正确配置与验证下限制可访问资源 | 配置天然正确，或模型服务不再收到输入 |

不同 profile 以同一系统用户运行时，通常仍拥有该用户的文件权限。目录名叫 private、指令说只读、模型曾拒绝一次，都不是隔离证明。

## 需要防什么

- 外部网页、消息、文档或工具输出诱导 Agent 忽略边界、读取无关资料、泄露或建立身份关联。外部内容是数据，不是用户授权。
- 把推测归属变成事实，把一次局部确认扩张为全量确认，把撤销前授权继续使用。
- 工具、插件、子代理、后台任务或其他 profile 越过预期读写范围。
- 将私有台账误提交 Git、Issue、PR、调试日志、截图或自动同步。
- 用户以为“本地文件/本地中转/关闭记忆”意味着不外发或零留存。

## 数据保存与外发清单

接入者逐项记录“已核实的事实 / 用户选择 / 未知项”，不把缺配置等同于关闭：

| 数据或通道 | 必须核实的问题 |
|---|---|
| 唯一私人台账 | 完整位置、允许读写者、备份/加密/删除策略、是否落在公开 Git 或同步范围 |
| 模型请求 | 用户输入、自动上下文、文件工具结果是否进入请求；实际服务商、中转、保留政策和处理位置 |
| 会话历史/摘要/缓存/日志 | 保存位置、保留方式、是否包含已读取的台账副本；清理是否覆盖数据库及备份 |
| 长期记忆/画像 | 是否启用、存在哪里、是否使用外部 provider；关闭后历史是否仍存在 |
| 插件/MCP/工具/子代理 | 实际可见目录、网络目的地、输入与输出、是否继承权限及额外认证 |
| 同步/系统备份/索引 | 应用之外是否还有云盘、备份、索引或其他同机进程；本框架没有能力保证它们关闭 |
| 后台行为 | 模型标题生成、review、遥测、调度器、渠道、服务和开机启动是否存在 |

私有 records 是人工维护的唯一事实源，不代表会话和日志不会留下讨论副本。关闭长期记忆不等于清空会话；本地代理地址不等于本地推理。外发政策不明就使用虚构输入，先不发送真实身份资料。

禁止收集密码、Token、Cookie、恢复码；不要让用户为了“核实权限”提供秘密。真实账号归属和公开身份映射即使没有密码，也可能是敏感资料。

## 是否需要系统隔离

| 场景 | 建议 |
|---|---|
| 虚构案例、纯建议、无敏感文件 | 可先用专用 profile 与最少工具，不必为文档试用搭复杂环境 |
| 正式维护真实身份/所有权/私人公开关联 | 优先建立可验证的读取边界；至少避免无关 profile 读取台账 |
| 同机助手大量接触外部消息/网页，且能运行命令或读任意文件 | 隔离优先级更高，不仅限制 Digital Lifeform profile，也限制这些不可信输入入口 |
| 需要保证不能读取、写入或联网 | 使用系统强制控制并单独验收；本项目文本规则不足 |
| 未来要执行账号发布、付款等动作 | 超出本框架当前能力，另行设计权限、审批和审计，不因已有委托记录就开放 |

可选路线是独立低权限系统用户与文件 ACL，或有限挂载的容器/受控远程环境。关键是资源实际不可访问：

- 独立用户仍需正确 ACL；同一 Windows 用户下的宽泛允许项不能靠多一个拒绝约定解决。不要未经同意修改用户主目录或系统 ACL。
- 框架只读挂载，私人记录仅挂给需要的执行环境；不要把整个用户目录、认证目录或容器控制 socket 一并挂进去。
- 明确网络出口和工具权限；管理员身份、提权工具、宿主机访问路径都可能破坏预期边界。
- 验证读、写和替代路径的实际结果，而不是只读配置。系统隔离不能阻止用户主动提交给模型的数据外发。

本项目不提供 ACL/容器自动配置，也不声称上述任一方案已在用户环境验证。

## 安全验证与失败处置

使用 [虚构验收集](../examples/acceptance-tests.md) 区分两种证据：模型行为检查与控制层测试。记录版本、有效权限、调用事件和文件变化；安全探针只针对获准的临时测试路径，不写真实框架或真实台账来试错。

发现越界时停止相关会话/工具入口，保留不含秘密的必要证据，先由用户决定修复及记录恢复。若曾泄露秘密，通过相应服务的正规渠道处理撤销/轮换；不要把秘密粘贴到公开反馈。删除本地日志不能保证撤回已发送的数据。

公开问题只使用虚构复现、最小非敏感配置和环境版本，不附完整环境、认证文件、私人路径、原始会话或可识别关系。如何贡献见 [贡献说明](../CONTRIBUTING.md)。
